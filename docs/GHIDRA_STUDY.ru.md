# Как использовано исследование Ghidra

Изучены части предоставленного `ghidra-master/ghidra-master/Ghidra/Features/Decompiler/src/decompile/cpp`, относящиеся к декомпиляции: `architecture.hh`, `translate.hh`, `pcoderaw.hh`, `action.hh`/`action.cc`, `coreaction.cc`, `flow.hh`, `block.hh`, `printc.hh`/`printc.cc`, `ifacedecomp.hh`. Это исследование нужных компонентов, а не заявление о построчном изучении всей Ghidra.

Ghidra отделяет декодирование машинных инструкций и получение промежуточных операций от анализа потока данных, управления, типов и печати языка. Translate/PcodeEmit описывают перевод инструкций, ActionDatabase и ActionPool — проходы преобразований, PrintC — вывод C-подобного представления. Отдельного универсального восстановления исходного C# вместе с IL2CPP metadata этот C-backend не делает.

Для поставленной задачи сначала понадобилось восстановить данные, связывающие нативные адреса с классами и методами. После этого можно генерировать managed-представление и проверяемые IL-тела, которые ILSpy печатает в C#.

## Исследование предоставленной сборки

Добавлен инструмент `tools/NativeInspect`: он читает PE-секции, экспорты, x64 .pdata, инструкции и перекрёстные ссылки через Iced. Он не загружает DLL и не исполняет код игры.

В GameAssembly.dll все ожидаемые il2cpp_* API переименованы. Имена были сопоставлены с их ссылками в UnityPlayer.dll. По вызовам найдена цепочка инициализации:

```text
API initialization wrapper: 0x180986660
Runtime initialization:    0x180915EF0
Metadata cache init:       0x180972F50
Global metadata init:      0x180920150
Metadata file loader:      0x180915800
```

Далее проанализированы обращения к заголовку и функции распаковки записей. В loader обнаружены:

- собственный заголовок размером 0x4EC;
- 256-байтовая таблица по RVA 0x5EB0450, читаемая из конкретного входного бинарного файла;
- последовательность xorshift64 (сдвиги 13, 7, 17) и индекс таблицы, получаемый XOR четырёх младших байтов состояния;
- отдельные начальные состояния для секций;
- смещения секций с добавками/вычитаниями;
- индексы переменной ширины 1/2/4 байта и специальные значения -1;
- изменённые форматы type/image/assembly-таблиц относительно ожидаемых Il2CppDumper.

Адреса registration из той же сборки:

```text
CodeRegistration:     0x1858D2770
MetadataRegistration: 0x185D7C940
```

`PixelWorldsMetadata.Normalize` воспроизводит нужную часть этой логики. Он сначала проверяет SHA256 обоих файлов, затем проверяет границы таблиц, количества записей, индексы строк, диапазоны методов и параметров. Новые структуры сериализуются в v31-совместимое представление. Профиль проверен на полном экспорте, а не только по появлению правильных четырёх байтов заголовка.

## Что реально делает приложение

```text
Папка игры
  → поиск native binary + metadata
  → стандартный parser или проверенный профиль Pixel Worlds
  → описания типов и методов + native registration
  → managed assemblies
  → проверенное восстановление ограниченного набора x64-методов
  → явные заглушки для неподдерживаемых тел
  → ILSpy + экранирование недопустимых C#-идентификаторов
  → C# + отчёт каждого метода
```

Исполняемый движок Ghidra не встроен и не выдаётся за часть приложения. Декодер и ограниченный lifter реализованы отдельно на C# с Iced; код Ghidra не копировался. Результаты и ограничения проверены в SAMPLE_CHECK.md.

Для полного восстановления сложных методов понадобится существенно более широкий анализ: CFG/SSA, моделирование регистров и стека, ABI вызовов, generic sharing, исключений, GC/barriers и рантаймовых helper-функций. Поэтому нынешний экспорт не обозначается как восстановление всей логики игры. Нативный анализатор принимает только полностью распознанные простые последовательности и отказывается от предположений.

## Обновление: CFG и Cpp2IL

Описание предыдущего ограниченного прохода выше — историческое. Теперь ScalarLifter переводит типизированные регистры, стек, условия, циклы и однозначные managed-вызовы в CIL. Добавлен отдельный экспериментальный Cpp2IL ISIL backend. Восстановлены также vtableMethods и interfaceOffsets. Полное исследование и актуальные ограничения — NATIVE_RECOVERY_RESEARCH.ru.md. Полное поведение игры всё ещё не восстановлено.
